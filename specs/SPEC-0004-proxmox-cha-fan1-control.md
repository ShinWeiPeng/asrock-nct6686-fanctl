# Proxmox CHA_FAN1 風扇控制

## Problem
ASRock A620AI WiFi 的 NCT6686D 位於 Proxmox 主機，Bazzite VM 只能控制直通 GPU。原 nct6683 驅動對 customer ID 0x1633 的 PWM 為唯讀。使用者希望機殼 CHA_FAN1 可由 Proxmox 正常控制。

## Solution
以 Linux hwmon nct6683 的晶片辨識及 EC 存取方式為基礎，提供受硬體身分及通道驗證限制的 C 核心模組、DKMS 建置與安裝/移除工具。首次載入保持唯讀及 BIOS 控制；僅在 CHA_FAN1 對應和極性經實機觀察確認後啟用控制。Proxmox coolercontrold 只綁本機，透過 SSH 通道使用 Web UI。保留 Bazzite GPU 控制及現有 VM 配置。

## User Stories
- 使用者可在 Proxmox 控制 CHA_FAN1，不依賴 Bazzite VM 是否啟動。
- 管理者可辨識控制通道、檢查失敗原因、切回 BIOS 並移除自寫模組。
